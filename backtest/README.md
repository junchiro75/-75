# XAUUSD+ Tick Backtest — 004 / 005 / 007

Infinox CFD 계좌, MT5 실전 운용 중인 세 개의 EA(`XAU_M10_BB_LIVE_004_FINAL`,
`XAU_M2_BB_LIVE_005_FINAL`, `XAU_M10_BB_LIVE_007_PROTECT05_PARTIAL10_FIX(3)`)를
2025.01 ~ 2026.09 XAUUSD+ 틱 데이터로 검증하기 위한 백테스트 엔진.

## 계좌/비용 가정

| 항목 | 값 |
|---|---|
| 심볼 | XAUUSD+ (Infinox) |
| 계약 단위 | 100 oz / lot (0.01 lot당 금값 $1 변동 = $1 손익) |
| 수수료 | $0.15 / 0.01 lot, 왕복(진입+청산 합산). 부분청산 시 청산되는 물량 비례로 부과 |
| 스왑/오버나이트 | 없음 |
| 체결가 | 매수 진입/숏 청산 = Ask, 매도 진입/롱 청산 = Bid (스프레드는 틱의 bid/ask 차이로 자동 반영) |
| 슬리피지 | 0 (틱 시점 그대로 체결 가정). 필요시 옵션으로 추가 가능 |

## 전략 공통 로직 (신호)

- 004/007: M10 봉, 005: M2 봉
- BB(20, dev=2.0, applied=Close) + BB(4, dev=4.0, applied=Open), 직전 완성봉 기준(과거참조, 미래참조 없음)
- 상승신호: close>open, high >= 두 상단밴드 모두 / 하락신호: close<open, low <= 두 하단밴드 모두
- R = |close-open| (신호봉 몸통)
- 신호 종가 대비 +0.95R 확장(ExtensionR) 도달 후, 그 익스트림에서 -0.10R 풀백(PullbackR) 시 **역추세(countertrend)** 진입
- 확장 대기 최대 72h(MaxExtensionHours), 풀백 대기 최대 72h(MaxPullbackHours)
- 동시 포지션 1개 제한(MAX1, 전략별 독립)

## 전략별 차이 (청산/자금관리, 실계좌 실행 기준)

- **004** (0.01 lot, SL=2R): +0.5R 도달 시 30% 부분청산 시도 → 0.01lot은 스텝 단위상 불가하여 **전체 물량 SL을 +0.25R로 이동**(락), TP=+0.9R. 타임아웃 없음(브로커 SL/TP까지 보유)
- **005** (0.01 lot, SL=2R): +0.5R 도달 시 전체 SL을 +0.25R로 이동(락), TP=+0.9R. 타임아웃 없음
  - EA 내부에 연구용 "가상(virtual) 30%/70% 분할" 통계가 있으나 이는 백테스트/리서치 참고용이며 **실계좌 P&L과 무관** — 본 엔진은 실계좌 로직(전량 락)만 사용
- **007** (0.02 lot, SL=2R): +0.5R 도달 시 전체 SL을 +0.25R로 이동(락). +1.0R 도달 시 **50% 부분청산**(0.02→0.01 청산 가능), 잔여 러너는 SL +0.25R 유지. 최종 목표가 = **신호봉 종가 + 반대방향 0.90R**(진입가 기준이 아님 — 확장/풀백으로 인한 진입가 슬리피지만큼 실현 R이 달라짐). 진입 후 168h(MaxPositionHours) 경과 시 시장가 강제 청산

## 데이터 입력

`backtest/data/`에 MT5 틱 export CSV를 월별로 넣습니다. 파일명 규칙: `XAUUSD+_ticks_YYYY-MM.csv`
(정확한 컬럼 포맷은 첫 파일 확인 후 로더에 맞춤 확정)

## 산출 지표

전략별 + 3전략 합산(포트폴리오) 기준:
- 총수익률, CAGR, 손익비, 승률, 기대값(expectancy)
- MDD(최대낙폭, 금액/%) 및 낙폭 지속기간
- Sharpe / Sortino
- 거래 횟수, 평균 보유시간
- 월별 수익 분포, 자본곡선(equity curve)
- 전략 간 상관관계
